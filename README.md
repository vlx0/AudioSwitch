# AudioSwitch

**Наушники ↔ колонки** — переключение устройства вывода одной кнопкой.

**Автор:** darkshade ([@vlx0](https://github.com/vlx0))

**365 дней open source** · **неделя 3 — «Окна и рабочий стол»** · день 21.

---

## Возможности

- Список устройств воспроизведения
- Кнопка / двойной клик / трей — переключить
- Звезда ★ — текущее по умолчанию

## Установка

```powershell
git clone https://github.com/vlx0/AudioSwitch.git
cd AudioSwitch
python -m pip install -r requirements.txt
pythonw run_audioswitch.pyw
```

Или `setup.bat` / `start.bat`.

Нужен Windows 10+ и Python 3.10+.
